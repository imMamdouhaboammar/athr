# AthR Product Blueprint

## 1. Product Thesis

AthR is a professional work network for digital marketing specialists where proof of work, professional reputation, collaboration, freelance opportunities, and hiring live together

The product model is:

**People -> Work -> Expertise -> Collaboration -> Opportunity**

The key product belief:

**Find the person whose work proves they can solve this**

AthR should not ask a hiring user to trust a title such as `Media Buyer, 5 years experience` without context

A better discovery result is closer to:

- Paid Social specialist
- Meta + TikTok
- DTC / Beauty
- Egypt + GCC
- Relevant case studies
- Current availability
- Confirmed collaborators
- Recommendations for the exact skill

## 2. Product Jobs

### Specialist jobs

- Build a credible professional identity quickly
- Show actual work without building a separate portfolio website
- Be discovered for the right type of work
- Make availability visible
- Find relevant opportunities
- Find trusted collaborators
- Build professional reputation from completed work
- Turn completed projects into stronger future evidence

### Hiring user jobs

- Describe a marketing need without writing a generic job post
- Discover specialists with relevant evidence
- Compare people by work context, not generic ratings
- Contact the right person quickly
- Hire one specialist or assemble several specialists later
- Build a reusable list of trusted people

## 3. Product Principles

### Work before biography

Show evidence before long self-description

### Specific before generic

Use marketing-specific specialties, channels, markets, industries, objectives and metrics

### Context before conversation

Messages should start from a project, opportunity, service or profile context when possible

### Reputation is multidimensional

Do not reduce professional trust to one star rating

### Social behavior must serve work

Follows, feeds, saves and recommendations should make professional discovery easier

### Keep V1 focused

Do not add complex payment, events, courses, general communities or heavy recommendation infrastructure before the core loop works

## 4. Primary Personas

### Independent specialist

Needs visibility, proof of work, opportunities and collaborators

### Senior specialist or consultant

Needs authority, selective opportunities, retainers and trusted referrals

### Agency specialist

May both offer work and hire collaborators

### Founder or business owner

Needs help translating a business problem into the right marketing specialist

### Marketing manager or CMO

Needs trusted specialists by channel, market, industry and availability

### Agency hiring user

Needs a recurring freelancer roster and later private talent pools

## 8. Signature Experience: Discovery by Evidence

Discovery result composition should answer four questions without requiring a profile click:

1. Who is this person
2. Why are they relevant to my need
3. What work proves that relevance
4. Are they realistically available

A result can contain:

- Identity and headline
- Primary specialty
- Relevant industries and markets
- Availability
- One or two matching work samples
- Relevant recommendation signal

## 9. Signature Experience: Collaboration Graph

Every confirmed project collaboration creates a useful professional relationship

Possible future uses:

- Frequently works with
- Trusted collaborator suggestions
- Crew creation
- Team recommendations
- Referral graph

V1 should only capture and confirm relationships reliably

## 10. Work Feed Model

Supported content types:

- Case Study
- Breakdown
- Teardown
- Experiment
- Availability update
- Collaboration request
- Opportunity

Avoid unrestricted generic social posting in the first version

The feed exists to answer:

- What good work is being published
- Who is doing it
- What can I learn from it
- Who is available
- What opportunities exist

## 11. Project Brief Model

A hiring user should describe the marketing situation using structured fields

### Business context

- Industry
- Business model
- Market

### Objective

- Sales
- Leads
- Awareness
- Retention
- Conversion improvement
- Acquisition cost reduction
- Other

### Marketing context

- Current channels
- Current spend when relevant
- Existing team
- Tools

### Need

- Required specialty
- Deliverables
- Start date
- Duration
- Availability
- Budget
- Individual or multiple specialists

The output is both an opportunity record and a better discovery query

## 12. Trust Model

Useful trust signals include:

- Confirmed collaborator
- Client verified project
- Repeat client
- Repeat collaborator
- Completed project
- Recommendation for a specific skill
- Verified identity
- Response reliability

A generic star rating can be added later only if it has a clear decision-making role

## 13. Growth Loops Built Into Product Behavior

### Work publication loop

Publish work -> get discovered -> receive conversation -> complete work -> publish stronger work

### Collaboration loop

Tag collaborator -> collaborator confirms -> both profiles gain relationship evidence -> users discover each other through shared work

### Hiring loop

Create brief -> discover specialist -> save/message -> complete project -> recommendation -> stronger future matching

### Follow loop

Discover useful work -> follow specialist -> see future work -> save/message/share -> increase qualified professional relationships

## 14. Product Success Criteria

The MVP is successful when users repeatedly perform the core loop without relying on a large feature set

Signals to watch:

- Specialists publish credible first work samples
- Hiring users click work before sending messages
- Search results lead to qualified profile visits
- Conversations are linked to meaningful work or opportunities
- Collaborator confirmations happen naturally
- Completed work generates new proof or recommendations

## 15. North Star

Working primary metric:

**Qualified work conversations created per active specialist**

Supporting metrics:

- Specialist activation rate
- Portfolio publication rate
- Work view to profile visit
- Profile visit to message
- Opportunity to relevant application
- Brief to conversation
- Conversation to completed project
- Project to recommendation
- Project to new portfolio evidence
