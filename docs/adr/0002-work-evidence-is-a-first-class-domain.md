# Treat work evidence as a first-class domain

AthR models Portfolio Projects, Case Studies, Work Metrics, collaborators, and verification state as durable professional evidence rather than generic social posts with attachments. This adds more structure than a conventional feed model, but preserves the product's core promise that discovery and trust are grounded in relevant work and lets the same evidence support profiles, search, applications, recommendations, and future verification without duplicating meaning across features.
